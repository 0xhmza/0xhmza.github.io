# 0xhmza.github.io

Personal site built with Jekyll using the Klise theme as a base.

## Run locally
- Install Ruby and Bundler, then run `bundle install`.
- Start the dev server with `bundle exec jekyll serve`.
- Open `http://localhost:4000` in your browser.

## Project layout
- Content pages and posts live in `_posts/`, `about.md`, `archive.html`, and `thanks.md`.
- Styles live in `assets/` and `_sass/`.
- Site configuration is in `_config.yml`.
