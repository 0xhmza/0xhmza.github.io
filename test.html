Physical Infrastructure

Everything starts here. Before a single packet can be secured, it must traverse physical hardware. Understanding cabling standards, switching hierarchy, power, and hardware security modules is essential. Physical security is also security — unescorted access to a switch means game over.

// THREE-TIER SWITCHING HIERARCHY WITH OOB MANAGEMENT
🔌
Access Switch
Layer 2. Connects end-user devices. 802.1Q VLAN tagging per port, PoE/PoE+ for APs and VoIP, storm control, port security (MAC binding), BPDU guard, and 802.1X NAC integration.
// VENDORS
Cisco Catalyst 9xxxJuniper EX Series Aruba / HPEUbiquiti UniFi Pro OpenWrt (SOHO)
🏗️
Core / Distribution Switch
Layer 3 switching. Inter-VLAN routing, ECMP load balancing, HSRP/VRRP redundancy, spanning tree root, LACP aggregation. Typical 10G/40G/100G uplinks. Must be redundant pair.
// VENDORS
Cisco Nexus 9xxxArista 7xxx Juniper QFXExtreme Networks Dell PowerSwitch
🔐
HSM — Hardware Security Module
Tamper-resistant hardware for cryptographic operations. Stores private keys for PKI/CA, SSL/TLS certificates, disk encryption keys. Required for PCI-DSS, eIDAS, FIPS 140-3 Level 3 (supersedes FIPS 140-2).
// VENDORS
Thales Luna Network HSMUtimaco AWS CloudHSMEntrust nShield SoftHSM2 (test only)
🖥️
Out-of-Band Management
Dedicated network for device management completely isolated from production. Console servers aggregate serial access. IPMI/iDRAC/iLO provide remote power/KVM. Critical for incident response on dead networks.
// VENDORS
Opengear CM/OMRaritan Dominion Vertiv AvocentPi-based OOB (DIY)
Physical Security Note: A physical attacker with 5 minutes at a switch can install a rogue device, mirror all traffic via SPAN, or reset credentials. Lock racks, disable unused ports, enable port security, and use tamper-evident seals on hardware.

Network Architecture & Segmentation

Network segmentation limits blast radius. A compromised printer should not reach your database. VLANs, micro-segmentation, NAC, and routing ACLs define your internal trust boundaries.

// VLAN SEGMENTATION — SECURITY ZONES WITH TRAFFIC CONTROL
🔀
NAC — Network Access Control
802.1X authenticates devices before they get a VLAN assignment. RADIUS backend validates identity. Posture checking: is AV running? Patches current? Certificate valid? Non-compliant devices go to quarantine VLAN.
// SOLUTIONS
Cisco ISEAruba ClearPass PacketFenceFreeRADIUS Forescout
🌐
SDN / Micro-segmentation
Software-Defined Networking moves policy from physical VLANs to software-defined policies. East-west traffic between VMs/containers on the same hypervisor can be controlled without hairpinning through a firewall.
// SOLUTIONS
VMware NSX-TCisco ACI OVS / OpenFlowCalico (K8s) Illumio
🔑
VPN Gateway
Site-to-site IPSec IKEv2 tunnels, client-to-site SSL/TLS. Modern deployments use WireGuard for its performance and simplicity. Split tunneling decisions are critical — full-tunnel adds latency but better security.
// SOLUTIONS
WireGuardOpenVPNStrongSwan Cisco AnyConnectPalo Alto GlobalProtect Tailscale
📡
SD-WAN
Software-Defined WAN overlays provide application-aware routing across multiple ISP links (MPLS, broadband, LTE). Replaces expensive MPLS-only WANs. Security must be built-in, not bolted-on.
// SOLUTIONS
Cisco Meraki SD-WANFortinet Secure SD-WAN VMware VeloCloudVyOS pfSense + WireGuard
Segmentation Best Practice (NIST SP 800-41): Every VLAN should have an explicit "deny all" default ACL, with only required flows permitted. The most common segmentation failure is allowing inter-VLAN traffic by default. Test segmentation quarterly with internal pen tests.

Perimeter Security

The classic "hard outside, soft inside" model is dead. Modern perimeters are multi-layered. DDoS scrubbing in the cloud, NGFW at the edge, IDS/IPS inline, WAF for web apps, forward proxy for egress control.

// PERIMETER SECURITY STACK — INBOUND + OUTBOUND TRAFFIC PATHS
🛡️
NGFW — Next-Gen Firewall
Stateful inspection + App-ID + User-ID + SSL decryption + integrated IPS + URL filtering. Understands application context, not just ports. Policy: "Allow HTTPS to SharePoint from Finance users" vs "Allow TCP/443".
// SOLUTIONS
Palo Alto PAN-OSFortinet FortiGate Cisco Firepower (FTD)Check Point Sophos XGSpfSense + Suricata OPNsense
👁️
IDS vs IPS — Key Differences
IDS (Detection): Passive tap/SPAN mode. Monitors and alerts only. Cannot block. Lower risk — a false positive won't cause downage. Best for learning baseline.

IPS (Prevention): Inline mode. Actively drops/resets malicious flows. High-fidelity rules are critical — a bad rule = production outage. Often built into NGFW.
// IDS/IPS SOLUTIONS
Snort 3Suricata 7Zeek (Detection) Cisco FTD IPSTrend TippingPoint
🌍
WAF — Web Application Firewall
Layer 7 protection. Blocks OWASP Top 10: SQLi, XSS, SSRF, path traversal, RCE. Detection modes: signature (OWASP CRS), positive model (whitelist), ML-based. Rate limiting, bot detection, API protection.
// SOLUTIONS
ModSecurity v3 + OWASP CRSNAXSI (nginx) Cloudflare WAFImperva WAF F5 Advanced WAFAWS WAF Fastly WAF (Signal Sciences)
🧪
Sandbox / File Detonation
Executes suspicious files in isolated VMs. Analyzes behavior: file writes, registry changes, network calls, process injection. Detects zero-days and polymorphic malware that bypass signatures. Integrates with email gateways and proxies.
// SOLUTIONS
Cuckoo SandboxCAPE Sandbox Palo Alto WildFireCheck Point SandBlast ANY.RUN (cloud)Joe Sandbox (community)

Endpoint Security

Endpoints are where attacks execute. Modern endpoint security goes far beyond antivirus — EDR provides full telemetry of every process, file, network connection, and registry operation. Combined with behavioral AI, it's the last line of defense.

🔬
EDR — Endpoint Detection & Response
Continuous recording of: process trees, network connections, file operations, registry changes, DLL loads, memory injection. Enables forensic timeline reconstruction and remote response actions (isolate, kill, remediate).
STRENGTHS
  • Behavioral detection
  • Remote isolation
  • Full telemetry
  • Threat hunting
TRADE-OFFS
  • Agent on every endpoint
  • Resource usage
  • Cloud dependency
  • Cost per endpoint

AV / EPP — Endpoint Protection Platform
Traditional signature matching + heuristics + sandboxing. EPP adds behavioral blocking, application control, device control, and vulnerability assessment. Still relevant as a first-pass layer but should not be the only layer.

HIDS / FIM — File Integrity Monitoring
Monitors kernel syscalls, login events, user commands, log files, and critical file hashes. FIM detects unauthorized binary/config modifications — often the first sign of a rootkit. PCI-DSS Requirement 11.5 (FIM) and CIS Control 3 (Data Protection) requirement.

Prevents sensitive data leaving endpoints. Content inspection of clipboard, USB/removable media, screen capture, email attachments, print. Understands PII, PCI, PHI via regex + ML classifiers. Critical for insider threat programs.

Vulnerability remediation at scale. OS + third-party app patching. CVE prioritization by CVSS + EPSS (exploitability). Rollback capabilities essential. Mean-Time-to-Patch (MTTP) is a critical security KPI. Automate what you can.

Only explicitly approved applications can execute. Strongest malware prevention control available — blocks all unknown executables by default. Operationally complex but highly effective in locked-down environments.

Identity & Access Management

Identity is the new perimeter. Per the Verizon DBIR, stolen credentials are involved in ~50% of breaches, and the human element (including phishing) features in ~68% of incidents. Layered identity controls — MFA, PAM, SSO, conditional access, and Zero Trust — are the highest-ROI security investments.

Zero Trust Architecture (NIST SP 800-207): Core tenets: (1) All data sources and computing services are considered resources. (2) All communication is secured regardless of network location. (3) Access to individual enterprise resources is granted on a per-session basis. (4) Access is determined by dynamic policy — including client identity, application, and observable state of the requesting asset. (5) The enterprise monitors and measures the integrity and security posture of all owned and associated assets. Phishing-resistant MFA (FIDO2/WebAuthn) is the critical first step.

ELK Stack — Elasticsearch, Logstash, Kibana

The ELK Stack (now Elastic Stack) is one of the most widely deployed log management and SIEM platforms. Elasticsearch provides distributed search and analytics, Logstash processes pipelines, Kibana visualizes, and the Beats family ships data from every source.

// ELASTIC STACK — FULL DATA PIPELINE ARCHITECTURE
ELK BEATS FAMILY
📄 Filebeat
Tails and ships log files. Modules for Apache, Nginx, AWS, Azure, GCP, Zeek, Suricata, Cisco, and 50+ more. Handles backpressure automatically.
Open Source
🪟 Winlogbeat
Ships Windows Event Logs. Critical events: 4624/4625 (login), 4688 (process create), 4720 (account create), 4732 (group change), Sysmon events.
Open Source
🌊 Packetbeat
Sniffs network packets and decodes protocols (HTTP, DNS, MySQL, Redis, MongoDB). Useful for application performance monitoring and detecting C2 over HTTP.
Open Source
📊 Metricbeat
Collects system + service metrics. CPU, memory, disk, network I/O, Docker container stats, Kubernetes pod metrics. Replaces most of what Nagios/Cacti do for metrics collection.
Open Source
🔒 Auditbeat
Collects Linux auditd events. User activity, file access, process execution, system calls. Maps directly to MITRE ATT&CK techniques. FIM and user tracking without OSSEC.
Open Source
🤖 Elastic Agent
Unified agent intended to consolidate all Beats. Single deployment, managed via Fleet Server. Integrations for 100+ data sources. Supports EDR (Elastic Defend) + observability in one agent. Legacy Beats still supported but Elastic Agent is the strategic direction.
BSL License
ELK vs OpenSearch: In January 2021, Elastic changed the Elasticsearch license from Apache 2.0 to SSPL+Elastic License. AWS forked it as OpenSearch (Apache 2.0). In August 2024, Elastic added AGPL as a third license option. OpenSearch maintains broad API compatibility and is widely used in self-hosted environments. Choose OpenSearch for fully open-source deployments; Elastic for commercial support, advanced ML, and the broader Elastic Security ecosystem.

Network Monitoring — Cacti, Munin, Zabbix

Network monitoring predates modern security tooling. SNMP polling, MRTG graphs, RRDtool databases — these tools remain essential for capacity planning, baseline establishment, and detecting anomalous traffic volumes that sophisticated threats generate.

// NETWORK MONITORING DATA FLOW — COLLECTION TO VISUALIZATION
🌵
Cacti
PHP/MySQL frontend for RRDtool. SNMP polling for bandwidth graphs. Ubiquitous in network teams since the early 2000s. The classic "how much bandwidth is that interface using?" tool. Supports custom scripts, OIDs, data templates.
PROS
  • Battle-tested
  • SNMP expert
  • Free/OS
CONS
  • Dated PHP UI
  • Poor alerting
  • No modern agents
Open Source — GPLCacti Plus (extensions)

Munin
Plug-and-play node monitoring with beautiful time-series graphs. Master-node architecture. 500+ plugins out of the box. Excellent for tracking resource trends over time. Stores in RRDtool. Simple Perl-based plugin API.
PROS
  • Simple setup
  • Rich plugins
  • Trend analysis
CONS
  • No real-time
  • Limited alerting
  • Slow at scale
Open Source — GPL

MRTG — Multi Router Traffic Grapher
The grandfather of network monitoring. SNMP polling → RRDtool → HTML graphs. Still found in legacy environments. Inspired Cacti. Monitors interface traffic in/out with simple threshold alerts. Perl-based, minimal dependencies.
Open Source
⚡

Enterprise-grade open-source monitoring platform. Agent-based and agentless. Supports SNMP, IPMI, JMX, HTTP checks, custom scripts. Powerful templating system. Built-in alerting with escalation policies. Proxy architecture scales to 100k+ hosts.

Packet Analysis & Traffic Forensics

"The packet never lies." Packet capture is ground truth for security investigations. From a quick tcpdump to full PCAP replay in Wireshark to petabyte-scale network forensics with Arkime — packet analysis remains the ultimate source of evidence.

🦈
Wireshark
The gold standard GUI packet analyzer. Decodes 3000+ protocol dissectors. Coloring rules, display filters, stream reassembly. Follow TCP stream to reconstruct sessions. Decrypt TLS with pre-master secret log files. Expert Info for anomaly flagging. Tshark is the CLI version for scripting and automation.
// USE CASES
Wireshark (GUI)Tshark (CLI) Dumpcap (capture only)
⚡
tcpdump
The essential CLI packet capture tool. Available on virtually every Unix/Linux system. Remote capture piped to Wireshark. BPF filters for precise capture. Write to pcap files for later analysis. Every security engineer must know tcpdump syntax.
// COMMON FILTERS
tcpdump (libpcap)
tcpdump -i eth0 -w cap.pcap
tcpdump host 10.0.0.1 and port 443
tcpdump 'tcp[tcpflags] & tcp-syn != 0'
tcpdump not arp and not icmp
🐙
Arkime (formerly Moloch)
Large-scale full packet capture and search system. Indexes packets in Elasticsearch for fast search. Stores pcap files on commodity disks. Web UI for security investigations. Can capture at 10Gbps+. Used in large SOCs for retrospective analysis after an incident.
// SOLUTIONS
Arkime (Apache 2.0)Malcolm (Arkime + Zeek bundle)
🔬
Zeek (Bro) — Protocol Analysis
Not just IDS — Zeek is a powerful protocol analyzer that generates structured logs (conn.log, dns.log, http.log, ssl.log, files.log). Zeek scripts can extract files from HTTP, decode custom protocols, and generate rich metadata without storing full PCAPs.
// OUTPUT LOGS
conn.log (flows)dns.log http.logssl.log (certs) files.lognotice.log (alerts)
🖧
NetworkMiner
Windows-based passive network forensics tool. Opens pcap files and automatically reconstructs files, images, messages, credentials from captured traffic. Excellent for malware traffic analysis. Free version is very capable; Pro adds PCAP replay.
NetworkMiner FreeNetworkMiner Pro
🧲
ngrep / scapy / nmap
ngrep: grep-like pattern matching on network traffic. Scapy: Python packet crafting and analysis library — build any packet you can imagine. Nmap: the essential network scanner and service fingerprinter.
ngrepScapy (Python) Nmap + NSEMasscan

Automates: IOC blocking (firewall API), endpoint isolation (EDR API), ticket creation (ITSM), user suspension (AD), phishing remediation (email API), evidence collection. Key metric: MTTR (Mean-Time-To-Respond) reduction — from hours to minutes.

Cloud & Container Security

Cloud environments require a fundamentally different security approach. Traditional firewalls don't protect S3 buckets. CSPM finds misconfigurations, CWPP protects workloads, CNAPP unifies them. Container security from image scan to runtime.

DNS Security & Filtering

DNS is the phone book of the internet — and also the #1 vector for C2 communication. DNS filtering blocks malware at the resolver level. DNSSEC validates authenticity. DNS logging is mandatory for any detection program worth its name.

🚫
DNS Filtering / RPZ
Response Policy Zones (RPZ) allow recursive resolvers to return NXDOMAIN or sinkhole responses for malicious domains. Blocks malware C2, phishing, malvertising at the DNS layer — before any connection is made. Also blocks DGA (Domain Generation Algorithm) domains via ML classification.
// SOLUTIONS
BIND9 + RPZPi-hole Unbound + blocklistsCisco Umbrella (Opendns) Infoblox BloxOneCloudflare Gateway Quad9 (DNS for Good)
🍓
Pi-hole
Network-wide ad and tracker blocking via DNS sinkhole. Deployed on a Raspberry Pi or Docker container. Blocks millions of malware/tracking domains. Admin UI shows top blocked domains per client. Add custom blocklists (IOC feeds). Loved by homelabbers and small businesses.
Pi-hole (Open Source)
📜
DNSSEC
Cryptographically signs DNS records to prevent DNS cache poisoning (Kaminsky attack) and BGP hijacking of DNS. RRSIG, DNSKEY, DS, NSEC records form the chain of trust. Required by .gov TLDs. Operationally complex — key rollover processes matter.
BIND9 (DNSSEC)PowerDNS Infoblox (DNSSEC mgmt)
🔒
DoH / DoT — Encrypted DNS
DNS-over-HTTPS (DoH) and DNS-over-TLS (DoT) encrypt DNS queries to prevent eavesdropping and ISP snooping. Security concern: clients using public DoH bypass corporate DNS filtering. Enterprise: force all DoH to internal resolvers or block port 853/DoH.
Unbound (DoT)Cloudflare 1.1.1.1 DoH Quad9 DoT/DoHCisco Umbrella
DNS AS A DETECTION GOLDMINE
🔴 DGA Domains
Algorithmically generated random domains queried rapidly. Pattern: lots of NXDOMAIN responses + high entropy domain names. Detection: entropy scoring + beacon frequency analysis.
🟡 DNS Tunneling
Data exfiltration or C2 over DNS TXT/NULL records. Pattern: unusually long subdomain labels, high query rate to single domain. Tools: iodine, dnscat2. Detection: query length + rate analysis.
🟢 Sinkholing
When a malware C2 domain is taken down, resolving to a sinkhole IP instead reveals infected hosts in your network. Monitor for queries to known sinkhole IP ranges to find compromised machines.

Wireless & RF Security

Wireless networks extend your attack surface beyond physical walls. WPA3, 802.1X RADIUS authentication, WIDS/WIPS, and RF monitoring are essential controls for any environment with wireless infrastructure.

📡
WPA3 / Enterprise Auth
WPA3-Personal uses SAE (Simultaneous Authentication of Equals) instead of PSK — no offline dictionary attacks. WPA3-Enterprise with 802.1X + EAP-TLS is the gold standard: each user authenticates with their own certificate. No shared passwords.

WIDS/WIPS — Wireless Intrusion Detection/Prevention
Detects: rogue APs, evil twin attacks, deauth flooding (DoS), unauthorized clients, ad-hoc networks, honeypot SSIDs. WIPS actively contains rogue devices by sending deauth frames (requires care — can disrupt legitimate clients).

RF Monitoring & Spectrum Analysis
SDR (Software Defined Radio) enables passive monitoring of the RF spectrum. Detect rogue transmitters, signal jammers, Bluetooth attacks (BlueSnarfing, BIAS), Zigbee vulnerabilities. HackRF One and RTL-SDR are affordable hardware.
GNU RadioGQRX (SDR receiver) Kismet (multi-protocol)
WiFi 6E / WiFi 7: WiFi 6E (802.11ax) added the 6 GHz band (UNII-5 through UNII-8), increasing available spectrum significantly. WiFi 7 (802.11be) introduces 320 MHz channels, Multi-Link Operation (MLO), and 4096-QAM. Security note: WPA3 is mandatory for WiFi 6E certification. Legacy WPA2-only devices cannot connect to 6 GHz networks — this is a security advantage, as it naturally excludes older, less secure clients.

Backup, Recovery & Business Continuity

Ransomware made backup sexy again. A tested, immutable, air-gapped backup is your last resort against a catastrophic breach. The 3-2-1-1-0 rule: 3 copies, 2 media types, 1 offsite, 1 offline/immutable, 0 errors on restore.

Ransomware Reality: Modern ransomware (REvil, LockBit, BlackCat) exfiltrates data BEFORE encrypting. Backup alone is not enough — you also need to contain the breach. Attackers specifically target backup systems — they will delete your Veeam repositories if they can reach them. Backups must be immutable and offline/air-gapped.
💾
Veeam Backup & Replication
Market-leading backup for virtual, physical, and cloud workloads. Instant VM recovery, SureBackup (automated restore testing), Veeam Cloud Connect (offsite), immutability on Linux repos (XFS). Free Community Edition up to 10 workloads.
Veeam Community (10 workloads) Veeam Universal License
🔒
Immutable Backup
Backup data that cannot be deleted or modified for a defined retention period. Implementations: S3 Object Lock (WORM), Linux XFS+ext4 immutable flag, tape (inherently offline), cloud vault. Critical: the backup server account should not have delete permissions on backup storage.
AWS S3 Object LockAzure Immutable Blob Restic (encrypted, dedup)BorgBackup
🌩️
Disaster Recovery & RTO/RPO
RTO (Recovery Time Objective): how long can you be down? RPO (Recovery Point Objective): how much data can you lose? These drive DR architecture decisions. Hot standby (minutes RTO), warm (hours), cold (days). Test your DR plan at least annually.
Zerto (continuous replication) AWS Elastic Disaster Recovery Bacula Enterprise-style

Open-source options are viable for smaller environments. Amanda, Bacula, BorgBackup, Restic all offer solid functionality. For enterprise: Veeam, Commvault, Veritas NetBackup dominate. Cloud-native: AWS Backup, Azure Backup offer policy-based protection.

3-2-1-1-0 Backup Rule: 3 copies of data, on 2 different media types, 1 offsite, 1 offline or immutable, 0 errors verified on restore test. The IBM Cost of a Data Breach Report (2024) found organizations with tested IR plans and immutable backups reduced breach costs by an average of $2.66 million compared to those without.

Compliance & GRC

Governance, Risk, and Compliance (GRC) translates business risk into security controls. Frameworks define what you must do; tools automate evidence collection and gap analysis.

PCI-DSS v4.0
Payment Card Industry Data Security Standard. 12 requirement categories for cardholder data protection. FIM (Req 11.5), log monitoring (Req 10), vulnerability scanning (Req 11.3), penetration testing (Req 11.4), access controls (Req 7-8). Quarterly ASV scans required. v4.0 took effect March 2024, full enforcement by March 2025.
ISO 27001:2022
International ISMS (Information Security Management System) standard. 93 controls in Annex A. Risk treatment plan maps business risks to controls. Certification requires third-party audit. Updated in 2022 to add cloud, threat intel, physical security controls.
NIST CSF 2.0
Framework with six functions: Govern, Identify, Protect, Detect, Respond, Recover. Profiles map current vs target state. Implementation tiers measure maturity. Widely used in US government and critical infrastructure. Free to use.
GDPR
EU data protection regulation. 72-hour breach notification to DPA. Data minimization, purpose limitation, right of erasure. DPO (Data Protection Officer) required for some organizations. Fines up to €20M or 4% global turnover.
SOC 2 Type II
AICPA trust service criteria: Security, Availability, Processing Integrity, Confidentiality, Privacy. Type I: controls exist. Type II: controls operate effectively over 6-12 months. Required by SaaS vendors selling to enterprises.
CIS Controls v8
18 prioritized controls. IG1 (basic), IG2 (foundational), IG3 (organizational). Control 1-2: asset inventory. Control 4: secure configuration. Control 6: access management. Control 8: audit log management. Control 13: network monitoring. Practical, actionable, free.

Security Frameworks Reference

Frameworks provide the language and structure to discuss, measure, and improve security posture. Every security professional must understand MITRE ATT&CK — it is the universal language of threat detection.

// MITRE ATT&CK ENTERPRISE — TACTICAL PHASES (SIMPLIFIED)
FRAMEWORKS & MODELS
MITRE ATT&CK
Adversary tactics, techniques, and procedures (TTPs) knowledge base. 14 Tactics, 200+ Techniques, 680+ Sub-techniques (Enterprise matrix). Used for detection engineering, threat hunting, red/purple teaming, and vendor evaluation. ATT&CK Navigator for coverage heat-mapping. ATT&CK for Cloud, Mobile, ICS variants also maintained. ATT&CK Evaluations benchmarks EDR products against real-world adversary groups.
Lockheed Martin Cyber Kill Chain
7 phases: Reconnaissance → Weaponization → Delivery → Exploitation → Installation → C2 → Actions on Objectives. Older model, linear view. Useful for understanding attack lifecycle but does not capture modern lateral movement and living-off-the-land. Use alongside ATT&CK.
Diamond Model of Intrusion Analysis
Four vertices: Adversary, Capability, Infrastructure, Victim. Each event connects all four. Enables pivot analysis — knowing one vertex helps discover others. Meta-features: timestamp, phase, direction, methodology. Used in CTI for campaign tracking and attribution.
OWASP Top 10 (2021)
Web application security risks: A01-Broken Access Control, A02-Crypto Failures, A03-Injection, A04-Insecure Design, A05-Security Misconfiguration, A06-Vulnerable Components, A07-Auth Failures, A08-Software/Data Integrity, A09-Logging Failures, A10-SSRF. Also: OWASP API Top 10, Mobile Top 10.
MITRE D3FEND
Defensive counterpart to ATT&CK. Maps defensive techniques to ATT&CK techniques. Categories: Harden, Detect, Isolate, Deceive, Evict. Helps security teams answer: "what defenses counter this technique?" Relatively new but rapidly growing in adoption.
NIST SP 800-53 Rev 5
Catalog of 1,000+ security and privacy controls organized into 20 families (AC, AT, AU, CA, CM, CP, IA, IR, MA, MP, PE, PL, PM, PS, PT, RA, SA, SC, SI, SR). Required for US federal systems (FISMA). Controls mapped to ATT&CK, CIS, and ISO 27001. Low/Moderate/High baselines via SP 800-53B.
